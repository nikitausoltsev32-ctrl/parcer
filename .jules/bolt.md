## 2024-06-25 - React Component Re-render Bottleneck with O(N) Array Transformations
**Learning:** Found components (e.g., `LeadTable` in `LeadReportList.tsx` and `LeadResultsCard` in `ChatPage.tsx`) suffering from performance bottlenecks because they were performing O(N) array transformations (like `map`, `filter`, and `reduce`) directly in the render function. This causes severe lag when the components also track high-frequency events in state, such as mouse coordinates (`onMouseMove` updating `hoverPos`) or text input (updating on every keystroke), since state updates trigger a full component re-render, leading to repeated expensive array computations.
**Action:** Always wrap O(N) array transformations (like sorting, reducing, filtering, or mapping) inside `useMemo` when working within a React component that may re-render frequently (e.g. from mouse movement or typing).
