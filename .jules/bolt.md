## 2024-05-17 - [Memoizing derived state arrays and hoisting expensive loop operations]
**Learning:** Found a specific performance bottleneck where tracking mouse position via `onMouseMove` events triggers a massive cascade of state-derived re-renders. When derived data like `companies = contactsToCompanies(contacts)` and `filtered = search ? companies.filter(...)` isn't memoized, moving the mouse by just one pixel will run array iterations and `.toLowerCase()` operations hundreds of times per second on the main thread, causing significant UI judder.
**Action:** Always wrap expensive derived arrays in `useMemo` when they are placed in components that have fast-changing state (like hover tracking, real-time typing, or mouse position). Additionally, hoist repetitive transformations like `.toLowerCase()` outside of loop/filter callbacks to avoid redundant allocations on every iteration.
