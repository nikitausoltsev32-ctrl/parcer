# Согласие на трансграничную передачу данных LLM-провайдерам

> Status: draft

## Суть
Сервис использует AI-модели зарубежных провайдеров для:
- работы чат-ассистента,
- генерации текстов писем,
- классификации входящей корреспонденции.

При использовании этих функций данные (ваш запрос в чате, данные контактов, которым пишутся письма, тексты входящих писем) передаются следующим компаниям:

| Провайдер | Страна | Что передаётся |
|---|---|---|
| Groq Inc. | США | Сообщения чата, параметры для tool-calling, тексты входящих писем (для классификации) |
| Alibaba Cloud (DashScope / Qwen) | Китай | Данные контактов + параметры для генерации писем |
| Zhipu AI (GLM) | Китай | Fallback, те же данные что у Groq/Qwen |

Эти провайдеры обрабатывают данные на своих серверах. Передача происходит по защищённому каналу (HTTPS).

## Согласие
Для использования AI-функций требуется отдельное согласие — чекбокс в настройках (либо при первом обращении к AI-функции). Без согласия AI-функции недоступны; базовый функционал (импорт CSV, ручная отправка, CRM) работает без AI.

## Отзыв согласия
В любой момент через `/app/settings/security` → «Отключить AI-функции». После отзыва данные перестают отправляться LLM-провайдерам. Ранее отправленные данные удаляются по запросу к провайдеру (у Groq — 24ч retention по API, у Qwen/GLM — согласно их политикам).
