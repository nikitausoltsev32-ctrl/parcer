# Политика обработки персональных данных

> Status: draft
> Подлежит замене на финальный юридически выверенный текст от юриста.

## Основные разделы (план)
1. Оператор — ИП/ООО «...», ИНН, адрес.
2. Категории обрабатываемых данных:
   - Данные Пользователя: email, имя, пароль (хэш argon2), бизнес-профиль, история чата.
   - Данные Адресатов (контактов Пользователя), загруженные Пользователем: email компании, имя контакта, телефон, сайт, заметки. Пользователь — контролёр этих данных; Сервис — процессор.
3. Цели обработки:
   - Предоставление функционала Сервиса.
   - Техническая поддержка.
   - Аналитика использования (агрегированная).
4. Правовые основания (ФЗ-152 ст. 6):
   - Согласие субъекта (Пользователь) — при регистрации.
   - Исполнение договора — для данных Адресатов (Пользователь подтверждает законность их обработки).
5. Хранение:
   - Supabase (Postgres + Storage).
   - Регион: EU (или РФ, когда доступно).
   - Срок: до удаления аккаунта + 90 дней (для восстановления).
6. Передача третьим лицам:
   - Supabase Inc. (Postgres, Storage) — cloud-провайдер.
   - Upstash (Redis) — кэш и очередь.
   - Groq (США), Qwen/Alibaba (Китай), Zhipu/GLM (Китай) — LLM-провайдеры. Детали — в `llm-data-transfer.md`.
   - Unisender Go — транзакционные письма (verify, reset).
   - ЮKassa — платежи.
7. Права субъекта данных (доступ, исправление, удаление, возражение).
8. Cookies и трекинг.
9. Контакты оператора по вопросам ПДн.
10. Версионирование и дата последнего обновления.
