# Согласие на обработку персональных данных

> Status: draft

Отдельный короткий документ/чекбокс при регистрации. Покрывает:
- Согласие Пользователя на обработку его собственных данных (email, имя, пароль-хэш, история использования).
- Ссылка на `privacy.md`.
- Право отозвать в любой момент через `/app/settings/security`.

Для данных Адресатов (контактов, которые Пользователь загружает) — отдельный чекбокс при первом импорте CSV с текстом:
> «Я подтверждаю, что имею право обрабатывать email-адреса и данные компаний, которые загружаю, и что мои письма будут соответствовать ФЗ-38 «О рекламе» и ФЗ-152 «О персональных данных».»
